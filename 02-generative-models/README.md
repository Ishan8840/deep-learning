# 02 · Generative models

These notes move from compact latent representations to iterative generation. The VAE and DDPM folders include image-generation code; the DiT and general flow-matching folders are study notes.

| Topic | What to look for |
| --- | --- |
| [01 · Autoencoder](01-autoencoder/README.md) | Deterministic compression and reconstruction |
| [02 · Variational autoencoder](02-vae/README.md) | Latent distributions, ELBO, and MNIST code |
| [03 · DDPM](03-ddpm/README.md) | Forward noise, reverse denoising, and MNIST code |
| [04 · DiT](04-dit/README.md) | Diffusion with a Transformer backbone |
| [05 · Flow matching](05-flow-matching/README.md) | Learning a vector field from noise to data |

The [robot policies](../04-robot-policies/README.md) chapter applies diffusion and flow matching to action sequences.
