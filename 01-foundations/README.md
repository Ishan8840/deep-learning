# 01 · Foundations

The first three topics build the tools used by the later models:

1. [Backpropagation](01-backpropagation/README.md) implements a NumPy network without autograd, including dense layers, ReLU, and softmax cross-entropy.
2. [Recurrent networks](02-recurrent-networks/README.md) introduce hidden state and the difficulty of long-range dependencies.
3. [Vision transformer](03-vision-transformer/README.md) shows how patch tokens and attention replace recurrence for an image classification example.

Read the topic notes first, then follow the linked code. The examples are deliberately small so the data flow is visible.
