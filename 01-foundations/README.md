# 01 · Foundations

The first five topics build the tools used by the later models:

1. [Neural network](01-neural-network/README.md) implements backpropagation in NumPy without autograd.
2. [CNN](02-cnn/README.md) learns local image features with shared filters and pooling.
3. [Recurrent network](03-recurrent-networks/README.md) introduces hidden state and the difficulty of long-range dependencies.
4. [Transformer](04-transformer/README.md) implements causal attention and character-level text generation in one file.
5. [Vision transformer](05-vision-transformer/README.md) applies attention to image patch tokens.

Read the topic notes first, then follow the linked code. The examples are deliberately small so the data flow is visible.
